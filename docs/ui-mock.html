      詳細

      
          
      
          
      
        
      
      
      

      
      
    
      

    
      
      
      画面にあるのは 3 つだけ
      
      
        
        
      • 送るファイル — ＋（Windows 標準のダイアログで複数選択）、ドラッグ＆ドロップ、エクスプローラーでコピーして Ctrl+V
        • 
        
      • 送り先 — 上の欄はホスト名か「このPC」、下の欄はフォルダ。どちらも ▾ で履歴から選べます
        • 
        
      • 転送開始
        • 
      
      

      
      考え方
      
      
        
        
      • サーバーへ送るときは、フォルダ欄に C:\work のようなサーバー上のパスを書くだけ（自動で \\HOST\C$\work に変換）
        • 
        
      • 共有フォルダへ送るときは、送り先を「このPC」にして \\fs01\... を書く（種類の切り替えは不要）
        • 
        
      • {datetime} などはフォルダ欄にそのまま書きます。下の 1 行に、実際に送られる先のパスが出ます
        • 
        
      • 接続状態やエラーも、送り先の下の 1 行と、ボタンの上の 1 行で表示します
        • 
        
      • 左端の ● をクリックすると、接続するアカウントを変えられます
        • 
      
      

      
      試せる操作
      
      
        
        
      • 送り先を SV-DB02 にする → ログオンが必要（パスワードに wrong と入れると失敗します）
        • 
        
      • SV-WEB01 へ転送 → アクセス拒否 → ［詳細］［ログオン…］
        • 
        
      • 存在しないホスト名（SV-TEST99）を入れる → 接続できません
        • 
        
      • 送り先を「このPC」にする → フォルダ欄が D:\Transfer\{datetime} に切り替わる
        • 
        
      • 一覧へファイルをドロップ、Delete で削除、Ctrl+Enter で転送開始
